一次 API 调用怎样完成？

每一步都不复杂，但顺序很重要。Agent 的各种高级能力，都会围绕这条请求链路继续扩展。

1
配置参数
准备 base_url、api_key 和 model_name。
2
组织上下文
把 system、user、历史回复放进 messages。
3
发送请求
程序把请求提交给模型 API 服务。
4
模型生成
模型读取上下文，生成下一段回答。
5
处理返回
程序取出回复，展示或交给下一步流程。

配置参数

程序先知道服务在哪里、自己有没有权限、这次要用哪个模型。没有这些配置，请求就不知道该发给谁，也无法通过鉴权。

base_url   = "https://api.example.com/v1"
api_key    = "YOUR_API_KEY"
model_name = "teaching-model"
