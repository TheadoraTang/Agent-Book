点击“下一步”，观察 System、User、Tool 和输出约束怎样一起组成模型真正看到的任务说明。

模型看到的上下文包
System
你是 TravelPlanAgent，回答要清晰、诚实，不编造实时信息。
User
我想去成都玩三天，预算不高，喜欢小吃，不想太赶。
Tool
天气工具返回：未来三天有小雨，适合安排一些室内备选。
Output Rule
请按“每日主题 / 上午 / 下午 / 晚上 / 提醒事项”输出。
System：先定工作方式
System 像是 Agent 的工作守则。它告诉模型自己是谁、应该遵守什么边界、什么事情不能随便编。
